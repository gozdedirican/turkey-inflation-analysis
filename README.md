# Turkey Inflation Analysis

> Basit bir veri analizi projesi — Türkiye enflasyon (ve ilgili finansal/ekonomik) göstergeleri üzerinde analizler.  

## 📄 Proje Hakkında  
Bu proje, Türkiye’de enflasyon ve ilgili ekonomik/finansal göstergelere dair geçmiş veriler üzerinden analizler yapıyor.  
Veriler CSV dosyalarında saklı. Analizler ise Jupyter notebook kullanılarak gerçekleştiriliyor. Amaç; enflasyon trendlerini, belki uygun görselleştirmeleri ve finans-ekonomi analizlerini göstermek.  

## 🛠️ Kullanılan Teknolojiler / Dosyalar  
- Python (Jupyter Notebook)  
- CSV veri dosyaları  
- Notebook dosyaları: `inflation_analysis.ipynb`, `currency_gold_analysis.ipynb` vb.
